## RF distance là gì?

RF (Robinson–Foulds) distance là khoảng cách(topological distance) đo khác biệt giữa hai cây tiến hoá dựa trên số phân tách nhánh khác nhau giữa chúng.

Được tính bằng: Số splits chỉ có trên cây A + số splits chỉ có trên cây B.

RF càng thấp thì hai cây càng giống nhau về topology (cấu trúc liên kết), càng cao thì càng khác.

##  RF distance trong IQ-TREE

https://iqtree.github.io/doc/

Mục Command Reference → Computing Robinson-Foulds distance

Các câu lệnh để tính  RF distance:
-rf tree_set1 tree_set2: Tính pairwise RF distances giữa hai tập cây khác nhau
-rf_all: Tính RF tất cả-với-tất cả trong một tập cây
-rf_adj: Tính RF giữa các cây liền kề trong tập

=> Nhận được kết quả là file chứa ma trận RF distances hoặc các giá trị RF giữa từng cặp cây.

Bước 2: ALIGNMENT từng gene bằng MAFFT

Chạy lệnh:
```
for g in ORF1ab S E M N; do
  seqkit grep -f acc_core5.txt genes/$g.fasta > genes/$g.core.fasta

```
Bước 3: Dựng cây gene bằng iqtree
```
for g in ORF1ab S E M N; do
    iqtree2 -s align/${g}_aln.fasta \
            -m GTR+G \
            -bb 1000 \
            -nt AUTO \
            -pre trees/${g}
done
```
Bước 4: 

Gộp tất cả gene tree vào 1 file

Chạy lệnh:

```
cat trees/E.treefile \
    trees/M.treefile \
    trees/N.treefile \
    trees/ORF1ab.treefile \
    trees/S.treefile > gene_trees.all.tree
```
Chạy RF: 
```
iqtree2 -rf_all trees/*.treefile
```
Mở kết quả:
```
cat gene_trees.all.tree.rfdist
```

*** Phân tích kết quả ***

- Cặp E với M, S với E/M có S với E/M => Có sự khác biệt ở mức trung bình 

- Cặp N với S có RF = 20 => topology gần giống nhau 

- ORF1ab với tất cả gene có RF = 90 => ORF1ab có topology rất khác so với các gene khác. Gen này quan trọng nhất, kết quả hợp lý vì nó chiếm tới 70% chiều dài genome và chứa nhiều vùng tiến hóa khác nhau.

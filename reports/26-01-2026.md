# SARS-CoV-2 là virus gì?

SARS-CoV-2 là virus corona gây ra bệnh COVID-19.

Tên đầy đủ: Severe Acute Respiratory Syndrome Coronavirus 2

Thuộc họ Coronaviridae (virus corona)

Là virus RNA sợi đơn, hướng dương (+ssRNA)

Bộ gen dài ~30.000 ký tự

# DNA khác gì RNA?

- Khác nhau về cấu trúc: DNA có A, T, G, C. RNA có A, U, G, C.

-Khác nhau về chức năng: DNA lưu trữ thông tin di truyền, RNA sao chép – truyền đạt – thực thi thông tin từ DNA.

# 2 Tải dữ liệu SARS-CoV-2

 Tải genome SARS-CoV-2 (FASTA)

 Chạy lệnh 
```
datasets summary virus genome taxon SARS-CoV-2 --as-json-lines > sars2.jsonl
```

datasets summary virus genome... → là lệnh trong NCBI Datasets command-line tool để in ra metadata (dưới dạng JSON Lines) của các genome virus theo taxon hoặc theo accession

NCBI trả về:

Hàng trăm nghìn genome

Mỗi genome có metadata:

accession

strain

collection date

host

country

length

> → ghi thẳng vào file sars2.jsonl 

tạo file sars2.jsonl chứa danh sách genome của taxon SARS-CoV-2, CMD k hiện gì -> thành công 

Bước tiếp theo: 
```
dataformat tsv virus-genome --inputfile sars2.jsonl --fields accession > accession.tsv

```
dataformat tsv virus-genome... -> Đây là phần của tool dataformat của NCBI Datasets — dùng để chuyển JSON Lines metadata thu được từ lệnh datasets summary thành bảng TSV (cột-dòng) theo các trường (--fields)

Bước này chính là lọc ra cột accession từ metadata

=> Tạo file accession.tsv

Accession = mã định danh duy nhất của một genome / sequence cụ thể

Taxon = đơn vị phân loại sinh học (taxonomy)

Ví dụ:

Cấp phân loại	Ví dụ

Species     	SARS-CoV-2

Genus	        Betacoronavirus

Family      	Coronaviridae


Bước  tiếp theo: tạo file acc30.txt 

Mở accession.tsv bằng Notepad

Dòng đầu là:

accession

→ xóa dòng này

Copy 30 accession đầu tiên, ví dụ:

OR857123.1
OU471040.1
...


Dán vào file mới tên: acc30.txt
BƯỚC tiếp: DOWNLOAD 30 GENOME 

```
datasets download virus genome accession ^
  --inputfile acc30.txt ^
  --include genome ^
  --filename sars2_30.zip
```

# Căn chỉnh genomic.fa
Chạy lệnh:

```
mafft ^
  --auto ^
  --thread -1 ^
  genomic.fa > genomic_aln.fa
```
giải thích: 

--auto: MAFFT tự chọn thuật toán phù hợp nhất
--thread -1: Dùng tất cả CPU core có sẵn

-1 = auto-detect

 Ví dụ:

máy 8 core → dùng cả 8, tăng tốc rất nhiều

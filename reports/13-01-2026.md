# Bước 7: Identifying most influential genes

Bây giờ chúng ta muốn tìm hiểu nguyên nhân dẫn đến sự khác biệt topology(cấu trúc liên kết) giữa các cây được suy luận từ single model và partition model.

Một cách tiếp cận là xác định những gene đóng góp tín hiệu phát sinh loài (phylogenetic signal) mạnh nhất cho cây này nhưng không cho cây kia.

Ta có thể làm điều này bằng cách xem gene-wise log-likelihood difference giữa hai cây T1 và T2.

Những gene có giá trị logL(T1) − logL(T2) lớn nhất sẽ ủng hộ T1.

Ngược lại, những gene có logL(T2) − logL(T1) lớn nhất sẽ ủng hộ T2.

Chạy lệnh : 

```
iqtree3 -s turtle.fa -p turtle.nex.best_scheme.nex -z turtle.trees -n 0 -wpl --prefix turtle.wpl
```

-z turtle.trees :	đưa vào 2 cây cần so sánh (T1, T2)

-n 0 :	không tìm cây mới, chỉ tính log-likelihood

-wpl :	ghi partition-wise log-likelihood

turtle.wpl.partlh :	file kết quả quan trọng nhất

Cách xử lý file turtle.wpl.partlh

## Bước 8 - Removing influential genes

Bây giờ chúng tôi cố gắng tạo ra một cái cây không có những gen "có ảnh hưởng" này. 
Để làm như vậy, sao chép partition file turtle.nex sang một file mới và Xóa các dòng định nghĩa charset của những gene có ảnh hưởng mạnh, sau đó lặp lại quá trình chạy IQ-TREE với mô hình phân vùng partition model (xem phần 4).

Các bước thực hiện: 

Copy file turtle.nex thành file mới turtle.rm_influential.nex, xóa 2 dòng gene 14 và 18 

charset gene14 = ...

charset gene18 = ...

Chạy lệnh IQ-TREE cho partition model 

```
iqtree3 -s turtle.fa -p turtle.rm_influential.nex -B 1000 -T AUTO --prefix turtle.rm
```

-s turtle.fa : file alignment

-p turtle.rm_influential.nex : partition file đã loại gene 14 & 18

-B 1000 : ultrafast bootstrap (1000 lần)

-T AUTO : tự động dùng nhiều CPU

--prefix turtle.rm : tất cả output bắt đầu bằng turtle.rm.*


Chạy xong có được file turtle.rm.iqtree, turtle.rm.treefile

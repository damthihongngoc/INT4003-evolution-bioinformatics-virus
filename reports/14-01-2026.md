# Các khái niệm
- Cây gen (Gene tree) là cây tiến hóa được suy ra từ 1 gên duy nhất.

- Cây loài (Species tree) là cây tiến hóa “thật sự” của các loài. Thể hiện: loài nào tách ra trước, loài nào gần nhau.

- Ultrafast bootstrap support biểu thị điều gì?

Giá trị UFBoot (0–100) trên mỗi nhánh nghĩa là:

Tỷ lệ % số bootstrap trees mà nhánh đó xuất hiện

Ví dụ:

UFBoot = 95 → nhánh đó xuất hiện trong 95% số cây bootstrap → rất đáng tin

UFBoot = 60 → độ tin cậy trung bình

UFBoot < 50 → nhánh yếu, không nên diễn giải mạnh

- Gene Concordance Factor (gCF) : gCF là tỷ lệ (%) các cây gene ủng hộ một nhánh cụ thể của cây loài

0% → không gene nào ủng hộ

100% → tất cả gene đều ủng hộ

- Site Concordance Factor (sCF) : sCF là tỷ lệ (%) site(vị trí nucleotit) thông tin trong alignment ủng hộ nhánh. 

~33% là mức trung lập

<33% → nhánh đối nghịch được ủng hộ nhiều hơn

100% → tất cả site đều ủng hộ

CẢNH BÁO 

- Bootstrap cao (~100%) nhưng gCF ≈ 0% hoặc sCF < 33% → KHÔNG TỐT

- gCF và sCF > 50% → rất đáng tin cậy


## Bước 9 - Concordance factors (Hệ số đồng thuận)

Cho đến nay, chúng ta vẫn giả định rằng cây gene (gene tree) và cây loài (species tree) là giống nhau. Tuy nhiên, trên thực tế, các cây gene thường không hoàn toàn trùng khớp với cây loài do nhiều nguyên nhân như: ILS, paralogy, nhiễu dữ liệu…

Vì vậy, trong bước này, chúng ta sẽ định lượng mức độ đồng thuận giữa các cây gene và cây loài thông qua concordance factor ( hệ số phù hợp ) (Minh et al., 2020).

Trước tiên, ta cần suy luận một cây gene cho mỗi partition (gene)

Chạy lệnh 
```
iqtree3 -s turtle.fa -S turtle.nex --prefix turtle.loci -T 2
```

Trong đó: 

-s turtle.fa : alignment tổng

-S turtle.nex : yêu cầu IQ-TREE xây dựng cây riêng cho từng partition (gene)

--prefix turtle.loci : tiền tố file

-T 2 : dùng 2 core CPU

 Kết quả nhận được file:

turtle.loci.treefile 

→ chứa tập hợp các cây gene, mỗi gene một cây, gồm 29 cây.

Bước tiếp theo là TÍNH gCF & sCF CHO CÂY PARTITION MODEL bằng cách chạy lệnh : 

```
iqtree3 -t turtle.nex.treefile --gcf turtle.loci.treefile -s turtle.fa --scf 100
```

Giải thích:

-t turtle.nex.treefile : cây loài (species tree) – partition model

--gcf turtle.loci.treefile : file chứa các cây gene

--scf 100 : dùng 100 quartet ngẫu nhiên để tính sCF

=> Kết quả nhận được 
- File turtle.nex.treefile.cf.tree: tree file where branches are annotated with bootstrap/gCF/sCF values. Cây có chú thích các giá trị bootstrap/gCF/sCF. 
- File turtle.nex.treefile.cf.stat: a table file with various statistics for every branch of the tree.Bbảng thống kê chi tiết cho từng nhánh.

Tương tự, có thể TÍNH gCF & sCF CHO CÂY bằng mô hình không phân vùng (unpartitioned model), bằng cách chạy lệnh:
```
iqtree3 -t turtle.fa.treefile --gcf turtle.loci.treefile -s turtle.fa --scf 100
```

## Bước 10 - Applying a mixture model

Bây giờ chúng ta sẽ thực hiện phân tích mô hình hỗn hợp (mixture model) theo Ren et al. (2025), trong đó mỗi vị trí (site) trong chuỗi được mô tả như một hỗn hợp của nhiều mô hình tiến hóa khác nhau.

Trong bài thực hành này, chúng ta sử dụng một mô hình hơi khác so với các phần trước, đó là GTR+FO+I+R3, đây là mô hình phù hợp nhất (best-fit) cho toàn bộ bộ dữ liệu rùa (turtle dataset).

Ước tính phát sinh loài theo mô hình này làm cơ sở: 

Mô hình 1 lớp (1-class model)

Chạy lệnh 
```
iqtree3 -s turtle.fa -m GTR+FO+I+R3 -B 1000 -T AUTO --prefix turtlebest
```

Tương tự, chạy lệnh dưới để sử dụng mô hình 2 lớp (mixture model with two separate classes)

```
iqtree3 -s turtle.fa -m MIX"{GTR+FO,GTR+FO}"+I+R3 -B 1000 -T AUTO --prefix turtle2
```

Tiếp tục với mô hình 4 lớp: 

```
iqtree3 -s turtle.fa -m MIX"{GTR+FO,GTR+FO,GTR+FO,GTR+FO}"+I+R3 -B 1000 -T AUTO --prefix turtle4
```

Tiếp tục với mô hình 6 lớp

```
iqtree3 -s turtle.fa -m MIX"{GTR+FO,GTR+FO,GTR+FO,GTR+FO,GTR+FO,GTR+FO}"+I+R3 -B 1000 -T AUTO --prefix turtle6
```
